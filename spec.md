# Specification

## Summary
**Goal:** Add four custom branded images to the "What Makes Us Special" section in the About page to make it more visually attractive.

**Planned changes:**
- Add four unique images to the value cards in AboutPage.tsx, one for each special value (Global Culinary Journey, Premium Quality Ingredients, Hygiene & Safety First, Family-Friendly Ambiance)
- Each image will incorporate Taste and Tales brand identity elements
- Images will be displayed above or beside the text content in each value card
- Maintain responsive layout across all screen sizes

**User-visible outcome:** Customers visiting the About page will see attractive, branded images for each of the four "What Makes Us Special" values, enhancing visual appeal and brand recognition.
